Senograf Uploader: Privacy Policy

Last updated: 14 November 2026

Who uses this tool

Senograf Uploader is an internal tool. It is used only by the owner of the Senograf YouTube channels to upload the owner's own videos to the owner's own channels. It is not available to the public.

What Google data it accesses

With the owner's permission, the tool uses these YouTube Data API scopes:

  • youtube.upload: to upload video files to the owner's channel.
  • youtube.force-ssl: to set the thumbnail and captions of those uploaded videos and to confirm which channel was authorized.

The tool reads only the authorized channel's ID and title, and only to make sure a video goes to the intended channel.

How data is stored

The OAuth tokens are stored only on the owner's own computer. No data is sent to any server other than Google's YouTube API. Nothing is sold, shared with third parties, or used for advertising.

Use of YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time from Google account permissions. Revoking access makes the tool stop working. Stored tokens are then deleted from the owner's computer.

Contact

Questions: the channel owner, through the YouTube channels listed on the home page.
